feat: initial release of WTPS frontend with clean UI and Firebase integration

This initial commit establishes the foundational Next.js architecture for the Waste Water Treatment Plant Management System (WTPS), introducing a professional enterprise UI and secure role-based authentication.

Core Implementations:
- build: initialize Next.js app router project and strict .gitignore configurations to prevent credential leakage
- style: transition from experimental glassmorphism to a clean, flat enterprise UI
- feat(auth): integrate Firebase Authentication and Firestore for RBAC
- fix(auth): resolve critical duplicate user record generation bug
- feat(profile): implement comprehensive /profile page with view/edit modes
- feat(admin): establish initial Admin Console foundation

This release solidifies the frontend architecture, preparing the application for the upcoming operator and dashboard data integrations.
